Sobre

O que é este site

Este é o meu site pessoal: um lugar para mostrar o que estou construindo enquanto aprendo a programar. Em vez de começar só pela teoria, decidi aprender fazendo, e cada página daqui foi uma lição prática.

Ele é feito só com HTML e CSS, sem nenhuma ferramenta extra, e construído com a ajuda do Claude Code, um assistente de programação com inteligência artificial. O código fica no GitHub e a Vercel publica o site sozinha a cada mudança que eu envio.

Meu maior desafio

Aprender a pedir. Trabalhar com uma IA parece fácil, mas descobri que o difícil é descrever com clareza o que eu quero — e depois entender o que foi alterado e por quê, em vez de só aceitar o resultado. Cada pedido mal explicado virou uma lição sobre como dividir uma ideia em passos pequenos e revisar cada um antes de seguir.
